# Shared Brain Instructions

This repository is an Obsidian-compatible shared memory vault. Follow these steps:

1. Read `00-索引/AI入口.md` and `40-协作/当前进度.md` at the start of a task.
2. Use `00-索引/AI数据层.md` to route to only the notes relevant to the task.
3. Before editing, inspect the current Git status and pull the latest shared changes when connected.
4. Keep facts, inferences, and unverified ideas distinct. Record sources and dates for external claims.
5. Only write stable, reusable, non-sensitive knowledge. Keep secrets, personal profiles, and private notes in ignored local paths.
6. Do not overwrite a note or shared progress written by another device. Use a new handoff note for parallel work.
7. Do not delete, bulk-move, publish, schedule, or change global tool configuration without explicit owner approval.
8. At the end, update shared progress or add a handoff when useful; report the files changed and any commit/push still needed.

Detailed behavior is defined in `00-索引/AI入口.md`, `30-方法/协作准则.md`, and `00-索引/共享脑与本地脑边界.md`.
