# AI Shared Brain Skill

Use this skill when a task needs cross-session project status, shared methods, error-prevention notes, or reusable workflows from the user's shared brain.

## Start

1. Read the repository's `AGENTS.md`, `00-索引/AI入口.md`, and `40-协作/当前进度.md`.
2. Use `00-索引/AI数据层.md` to select only task-relevant notes.
3. Check Git status and sync before editing if the repository is connected.

## During work

- Follow `30-方法/协作准则.md` and the privacy boundary.
- Treat new facts as candidates until checked. Keep source, date, and confidence where useful.
- Never add credentials, private profiles, raw conversations, or unrelated personal notes to the shared repository.
- Preserve existing content. Do not delete, overwrite concurrent work, publish, or modify global tool settings without owner approval.

## Finish

- Store only durable, reusable, verified knowledge that is appropriate to share.
- Update `40-协作/当前进度.md` when the shared state changes; create a new handoff file for parallel work.
- Report changed files and whether changes were committed and pushed. Do not claim a sync that did not happen.
