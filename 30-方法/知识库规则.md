# 知识库规则

## 写入门槛

只有至少满足以下一项，才考虑沉淀：未来任务会复用、重要决定影响后续工作、问题容易重复发生、流程具有明确复用价值。必要时先放入待审 Inbox；知识库不是聊天记录。

## 页面质量

- 一页一个主题，标题具体；提供来源、日期和适用范围。
- 标出事实、推断和待确认内容；不把模板占位符当作已部署内容。
- 写入前搜索已有页面，避免重复；优先补充原页或建立链接。
- Frontmatter 遵循 `字段规范.md`，只保留有实际用途的字段。
- 新建/移动文件后更新 `00-索引/首页.md` 或 `00-索引/AI数据层.md`。
- 技能按 `50-技能/模板/SKILL.md` 编写，包含输入、可执行步骤和完成标准。

## 生命周期

保留来源和 Git 历史。过时内容可标注 `status: archived` 并说明替代方案；删除前先确认没有依赖链接且得到仓库所有者授权。
