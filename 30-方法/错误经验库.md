# AI 错误经验库

只收录已复现或有证据支持、能帮助未来任务预防的经验。候选条目需去除个人标识和敏感数据；推断不能伪装成已确认根因。

## 使用方式

任务关键词与条目匹配时，先阅读预防规则。新增前搜索相近条目；相同根因优先补充旧条目。

## 条目模板

```markdown
### E001：简短且可检索的标题
- 日期：YYYY-MM-DD
- 来源：复现 / 用户纠错 / 官方文档 / 其他
- 关键词：具体短语，使用逗号分隔
- 触发场景：
- 现象：
- 根因：已确认 / 推断（依据：）
- 预防规则：下次遇到该场景，先做什么或避免什么
- 适用范围与例外：
```

## 已确认条目

暂无。不要把模板示例或尚未复现的假设记成真实错误。
