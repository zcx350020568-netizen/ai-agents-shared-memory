# 知识收集工作流

```text
来源发现 → 收件箱待审 → 核对与去敏 → 去重 → 分类沉淀 → 更新索引
```

## 1. 捕获来源

把有潜在复用价值的外部资料或会话结论记到 `90-其他/收件箱.md`，包含标题、来源链接、日期、简短摘要和待确认项。没有来源的外部事实先标为待核查。

## 2. 审阅

- 确认资料与长期目标相关；低价值材料可以忽略。
- 核对原始来源，区分作者结论与自己的推断。
- 移除凭据、个人信息、第三方隐私和受保密约束的原文。
- 对需要分享个人背景或决定的内容，先由仓库所有者确认。

## 3. 去重与归档

- 先按 URL、DOI、项目 ID 等稳定标识去重，再按标题和主题人工比较。
- 已有页面足够好时补充新信息和来源；有分歧时记录两种说法及日期。
- 合并前保留原页要点和链接；不因“看起来重复”自动删除。
- 分类后更新首页或 AI 数据层索引。

## 4. 状态建议

`pending` 表示待审，`accepted` 表示已核对并归档，`rejected` 表示不采纳并可记录理由。状态是提示，不代表自动执行。
