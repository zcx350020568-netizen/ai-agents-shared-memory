# 通用 AI 接入提示

把下面内容复制到能访问本地文件的 AI 工具项目指令或工作区说明中，并把“本仓库”替换成实际路径：

```text
你正在使用一个由用户维护的 Obsidian + Git 共享记忆库。

开始任务：
1. 读取本仓库的 AGENTS.md、00-索引/AI入口.md、40-协作/当前进度.md。
2. 按 00-索引/AI数据层.md 仅加载当前任务相关文件，不遍历整个 Vault。
3. 检查 Git 状态。若远端有新变更，先拉取并阅读，不覆盖他人工作。

执行期间：
- 区分事实、推断和待确认信息；外部事实记录来源和日期。
- 只有稳定、可复用、经核实且适合共享的内容才写入长期知识。
- 密钥、账号信息、个人画像、私人笔记和未筛选的对话不得写入共享仓库。
- 不删除、覆盖、批量迁移或对外发布内容，除非用户明确授权。
- 并行任务使用新的 40-协作/会话交接/ 文件；避免多人同时编辑当前进度页。

结束任务：
- 有跨会话价值时更新对应笔记；否则不为凑数而写记忆。
- 更新 40-协作/当前进度.md，或创建独立交接页说明结果、未完成项和下一步。
- 汇报改动文件及 Git 提交/推送状态；不要声称未实际执行的同步已完成。
```
