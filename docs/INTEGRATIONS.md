# AI 工具接入

所有工具都从同一个本地克隆目录读取 Markdown。打开仓库并不自动授权 AI；在工具本身支持的本地文件/工作区权限范围内接入。

## 通用入口

把下面这段加入工具的项目级说明、工作区指令或会话开始提示：

> 开始任务前读取本仓库的 `AGENTS.md`、`00-索引/AI入口.md` 和 `40-协作/当前进度.md`。按 `00-索引/AI数据层.md` 只读当前任务相关笔记。结束时按知识库规则沉淀经核实且适合共享的内容；必要时更新进度或新建交接。不要写密钥、私人资料或未筛选的对话。修改后汇报文件和需要提交的变更。

不能读取仓库文件的网页 AI 只能使用你手动粘贴的必要入口和资料，不会自动同步。

## 工具入口文件

- **Codex / 通用 Agent**：将仓库作为工作区打开，读取根目录 `AGENTS.md`。
- **Claude Code**：在该仓库工作时读取根目录 `CLAUDE.md`；也可把通用入口加入项目级说明。不要用脚本覆盖 `~/.claude` 中既有内容。
- **支持 Agent Skills 的工具**：将根目录 `SKILL.md` 作为可选入口；需要复制到工具专属技能目录时，先查看该工具官方的技能安装说明，并避免覆盖已有技能。
- **Gemini CLI**：在项目级指令中引用 `GEMINI.md` 和 `AGENTS.md`。
- **Cursor**：仓库内 `.cursor/rules/shared-brain.mdc` 是一个项目规则入口。
- **GitHub Copilot**：仓库内 `.github/copilot-instructions.md` 是一个项目规则入口。
- **Hermes、WorkBuddy、DeepSeek 和其他工具**：使用上面的通用入口，或在工具提供文件访问时指向仓库目录。若工具的 hooks/config 支持读取文件，可按官方文档手工配置；模板不会默认写入这些工具的全局配置。

具体产品功能和配置路径会随版本变化。接入前请对照当前工具的官方文档；如果某工具无法读取本地仓库，就使用手动上下文方式。

## 避免多工具写冲突

- 把 `40-协作/当前进度.md` 当作单写者状态页。
- 并行任务各自创建 `40-协作/会话交接/YYYY-MM-DD-主题.md`。
- Git 冲突先查看双方 diff，再合并，不要自动丢弃一侧。
