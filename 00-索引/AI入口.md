# AI 入口

本页是执行约定，不是要求每次读取整个 Vault。按当前任务选择少量相关笔记，避免无关扫描和重复上下文。

## 每次会话开始

1. 阅读 `40-协作/当前进度.md`，确认共享目标、最新决定和待办。
2. 在 `00-索引/AI数据层.md` 按任务关键词路由；通常只再读 1–3 个相关页面。
3. 检查 Git 状态和近期变更。连接远端时先拉取；若无法同步，不要声称已读取或更新远端。
4. 按 `30-方法/协作准则.md` 处理事实核验、权限和冲突。

## 任务路由

| 当前任务 | 优先阅读 |
| --- | --- |
| 维护 Vault、分类、命名、Frontmatter | `30-方法/知识库规则.md`、`30-方法/字段规范.md` |
| 收集外部资料、导入笔记、去重 | `30-方法/知识收集工作流.md`、`00-索引/共享脑与本地脑边界.md` |
| 处理曾经踩过的坑或用户纠错 | `30-方法/错误经验库.md`、相关项目说明 |
| 项目规划、架构、多个方案 | `30-方法/协作准则.md`、项目页 |
| 共享大脑维护或健康检查 | `30-方法/自我维护机制.md`、`30-方法/知识库规则.md` |
| 执行可复用流程 | `50-技能/README.md`、相关 `SKILL.md` |
| 无法判断归属 | `40-协作/当前进度.md`、`00-索引/首页.md`；先保持内容待审 |

## 写入与会话结束

- 只把稳定、可复用、经过核对且允许共享的内容写入长期知识；临时讨论不自动变成记忆。
- 外部事实尽量记录原始来源和日期，明确区分事实、推断与待确认项。
- 个人资料、账号信息、密钥、隐私内容和未经筛选的对话只放本地忽略路径。
- 修改前后查看 diff；不覆盖未同步工作，不删除或批量迁移既有知识。
- 有共享状态变化时更新 `40-协作/当前进度.md`；并行任务另建会话交接文件。
- 结束时说明写了什么、未完成什么，以及是否已提交和推送。

## 自动化边界

本仓库的“自我维护”默认是可审阅清单，不会自行安装定时任务、发送数据或自动删除/重写页面。任何脚本只对明确指定的文件夹生效。
