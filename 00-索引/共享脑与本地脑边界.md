# 共享脑与本地脑边界

## 可以考虑共享

- 可复用且不含个人敏感信息的方法、技能、决策和已核验错误预防规则。
- 为跨会话工作所必需的项目状态、待办和公开资料链接。
- 用户明确选择加入共享库、并完成去敏的笔记。

## 始终留在本地

- 密码、API key、Cookie、验证码、访问令牌、私钥和 `.env`。
- 账号/身份资料、个人画像、私人日记、医疗/财务/家庭等隐私内容。
- 受保密义务约束的原文、未经筛选的聊天、日志或附件。
- 未经用户明确确认、无法判断能否对其他设备或协作者开放的内容。

推荐把私密资料放在被 `.gitignore` 忽略的 `本地私有/`，或文件名以 `.local.md` 结尾。不要把已有私人 Vault 整体复制进公共仓库。

## 写入前检查

1. 未来的其他设备和已授权 AI 是否确实需要这条信息？
2. 是否包含身份标识、凭据、个人信息或第三方隐私？
3. 事实是否有来源，推断是否明确标注？
4. 是否可以只共享抽象后的结论？
5. Git diff 中是否有不该离开本机的内容？

仓库设为 Private 仍不能替代隐私审查；协作者权限、凭据和已下载副本也需要单独管理。
